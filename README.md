# Multi School Management SaaS Script

EduSphere is a multi-school, multi-branch school and college management system that you run as your own SaaS business. It’s built with Laravel 12, Livewire 3, Alpine.js, Tailwind CSS v4 and MySQL. Schools sign up by themselves with a free trial and choose a Starter, Standard, Professional or Enterprise plan. Each school gets its own database and its own address (yoursite.com/schoolcode). Billing is manual by bank or UPI, or online through Stripe, Razorpay or PayPal, and the price adjusts fairly when a school changes plan. The system covers student profiles and admissions, ID cards and certificates, staff leave and payroll, offline attendance, automatic timetables, homework and online exams. It also handles marks and report cards with QR verification, fees with late fines and online payment, transport, library, hostel, inventory and health. Schools can send SMS, WhatsApp and push notifications, and parents and students get an installable app. A browser installer and one-click updater mean no SSH, Composer or Node is needed. Buyers get the complete source code with no encryption and no domain limits. It suits entrepreneurs who want to start a school software business, as well as school groups that want their own self-hosted system.

Most school software is built for one school. To sell it to many schools you have to install it again for each one, keep the data apart by hand and chase every school for payment. EduSphere is built to be sold. Each school signs up, gets a free trial, picks a plan and gets its own database. Your super admin panel handles plans, billing and every school from one place. Each school gets a full set of tools for students, staff, teaching, exams, fees and campus life, plus an installable app for parents and students.
